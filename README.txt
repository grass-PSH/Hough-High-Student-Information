Hough High Student Information — website files
Made with Sitewright (https://ashlitlabs.com/builder/)

HOW TO PUT THIS SITE ONLINE
1. Unzip this file.
2. Upload EVERYTHING inside the folder (keep the css, js and assets folders) to your
   hosting's web root — on cPanel that is usually public_html.
   You can use the cPanel File Manager ("Upload" then "Extract"), or FTP.
3. Visit your domain. index.html is your home page.

Other hosts work too: Netlify, Vercel, GitHub Pages, Cloudflare Pages — just drag the
folder in. 
PAGES
  index.html  –  Home
  faq-board.html  –  FAQ Board
  classes-board.html  –  Classes Board

EDIT LATER
Open Sitewright and choose "Import" with this ZIP file (or sitewright-project.json)
to keep editing. Your images are included.
